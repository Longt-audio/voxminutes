# VoxMinutes MVP Frontend UI 方案

> 本文档只描述 UI 方案，不实现代码。前端实现将在后端架构确定后进行。

## 1. 设计原则

- **简洁优先**：MVP 只保留核心功能，减少用户认知负担。
- **本地优先**：强调隐私、离线、数据不上传。
- **快速开始**：打开应用后，最常用的操作（开始录音）要在 1 步内完成。
- **可扩展**：为后续付费功能（云端 ASR、AI 总结、团队）预留入口，但当前不显示或置灰。

## 2. 页面结构

```
┌────────────────────────────────────────────┐
│  Sidebar (左侧边栏)                          │
│  - 录音 / 转录                                │
│  - 历史记录                                   │
│  - 设置                                      │
├────────────────────────────────────────────┤
│  Main Content (右侧主区域)                    │
│  - 根据路由显示不同页面                        │
└────────────────────────────────────────────┘
```

## 3. 页面路由

| 路由 | 页面名称 | 说明 |
|------|----------|------|
| `/` | 录音主页 | 实时录音控制、转录文本展示 |
| `/history` | 历史记录 | 录音/转写列表、搜索、导入 |
| `/settings` | 设置 | 模型路径、ASR 引擎、音频设备、导出目录 |

明确移除的页面（MVP 不做）：
- `/live-translate` 实时翻译
- `/translate` 翻译
- `/tts` 语音合成
- `/help` 帮助（可保留为关于页）
- 划词翻译、浮动窗口、字幕悬浮窗

## 4. 录音主页（/）

### 4.1 布局

```
┌────────────────────────────────────────────┐
│  Sidebar                                    │
├─────────────┬──────────────────────────────┤
│             │  录音控制栏                      │
│             │  [开始录音] [停止录音]            │
│             │  状态：就绪 / 录音中 / 处理中      │
│             ├──────────────────────────────┤
│             │  转录文本区                      │
│             │  --------------------------------  │
│             │  00:00:05 这是第一句转录文本        │
│             │  00:00:12 这是第二句转录文本        │
│             │  --------------------------------  │
│             │  （可编辑、选择文本）               │
│             ├──────────────────────────────┤
│             │  音频输入选择                      │
│             │  [麦克风] [系统音频]                │
│             │  ASR 引擎：[X-ASR ▼] [SenseVoice ▼]│
│             │  语言：[中文 ▼] [英文 ▼] [Auto ▼] │
└─────────────┴──────────────────────────────┘
```

### 4.2 交互

- 点击 **开始录音** 后：
  - 按钮变为 **停止录音**
  - 状态显示 "录音中"
  - 转录文本区实时追加内容
  - 使用 `transcript-update` Tauri event 接收后端数据

- 点击 **停止录音** 后：
  - 状态显示 "处理中"
  - 等 finalize 完成后，状态变为 "已完成"
  - 自动保存到历史记录

- 文本区支持：
  - 实时滚动
  - 点击某行可定位音频时间（可选，MVP 可不做）
  - 编辑文本后保存（修正转录结果）

## 5. 历史记录页（/history）

### 5.1 布局

```
┌────────────────────────────────────────────┐
│  Sidebar                                    │
├─────────────┬──────────────────────────────┤
│             │  [导入音频文件]  [搜索...]        │
│             ├──────────────────────────────┤
│             │  列表视图                       │
│             │  ┌────────────────────────┐    │
│             │  │ 2026-07-17 会议录音     │    │
│             │  │ 10:23 | 中文 | 5分32秒  │    │
│             │  └────────────────────────┘    │
│             │  ┌────────────────────────┐    │
│             │  │ 访谈录音                 │    │
│             │  │ 09:15 | 英文 | 12分08秒  │    │
│             │  └────────────────────────┘    │
│             │  ...                            │
└─────────────┴──────────────────────────────┘
```

### 5.2 交互

- 点击某条记录：
  - 展开右侧详情（或进入详情页）
  - 显示完整转录文本、可编辑
  - 显示操作按钮：
    - 导出 TXT
    - 导出 SRT
    - 导出 Markdown
    - 删除

- 导入音频文件：
  - 选择本地音频文件（wav/mp3/m4a/flac）
  - 后台转写，完成后加入列表

## 6. 设置页（/settings）

### 6.1 分组

**ASR 模型**
- 模型目录：输入框 + 选择文件夹按钮
- 默认 ASR 引擎：X-ASR / SenseVoice 单选
- 默认语言：中文 / 英文 / 自动检测
- 模型下载按钮：调用 `download-models.ps1` / `download-models.sh`

**音频**
- 录音设备：下拉选择
- 系统音频设备：下拉选择（用于录制电脑播放的声音）
- 采样率：16kHz（默认，只读）

**导出**
- 默认导出目录：输入框 + 选择文件夹按钮

**高级（预留）**
- 远程 ASR API：输入框（占位，当前不可用）
- 云端 ASR API Key：输入框（占位，当前不可用）

## 8. 状态管理

继续使用 Zustand，简化 store：

```typescript
interface AppState {
  isRecording: boolean
  recordingStatus: 'idle' | 'recording' | 'processing' | 'completed' | 'error'
  currentRecordingId: string | null
  transcriptSegments: TranscriptSegment[]
  asrEngine: 'xasr' | 'sensevoice'
  language: string
  inputDevice: string | null
  outputDevice: string | null
  modelDir: string
  exportDir: string
}
```

## 9. 与后端交互的 Tauri Commands

MVP 需要暴露给前端的核心命令：

| command | 输入 | 输出 | 说明 |
|---------|------|------|------|
| `start_recording` | `{ engine, language, inputDevice, outputDevice }` | `recording_id` | 开始录音 |
| `stop_recording` | `recording_id` | `bool` | 停止录音 |
| `list_audio_devices` | - | `device[]` | 获取音频设备 |
| `import_audio_file` | `{ path, engine, language }` | `recording_id` | 导入音频文件 |
| `list_recordings` | `{ page, pageSize }` | `recording[]` | 获取历史记录 |
| `get_recording` | `recording_id` | `recording + segments[]` | 获取详情 |
| `update_recording_title` | `{ id, title }` | `bool` | 修改标题 |
| `delete_recording` | `id` | `bool` | 删除记录 |
| `update_segment_text` | `{ id, text }` | `bool` | 修改转录文本 |
| `export_recording` | `{ id, format, path }` | `path` | 导出 TXT/SRT/Markdown |
| `get_settings` | - | `settings` | 读取设置 |
| `save_settings` | `settings` | `bool` | 保存设置 |
| `get_model_dir` | - | `path` | 获取模型目录 |
| `set_model_dir` | `path` | `bool` | 设置模型目录 |

## 10. 视觉风格建议

- 使用现有 Tailwind + shadcn/ui 组件库
- 配色：浅色主题，主色可用蓝/青色系
- 字体：系统默认无衬线字体
- 录音中按钮：红色，强调状态
- 转录文本区：等宽或系统字体，清晰可读
- 侧边栏：简洁图标 + 文字

## 11. 后续付费版入口预留

在不破坏 MVP 简洁性的前提下，可以这样预留：

- 设置页底部增加 "高级功能" 分组，当前显示为禁用状态：
  - 云端 ASR（Pro）
  - 自动会议纪要（Pro）
  - 多说话人识别（Pro）
  - 实时翻译（Pro）
- 历史记录中某些导出格式可标为 "Pro"

这些在 MVP 中仅作展示，不实现功能，也不引导付费，避免影响开源体验。

## 12. 不做的功能清单

- 实时翻译 / 同声传译
- 划词翻译
- TTS / 语音合成
- AI 总结
- 多模型管理（LLM/翻译/TTS）
- 浮动窗口 / 字幕悬浮窗
- 系统托盘复杂菜单
- 在线更新
- 许可证管理
- 团队共享
- 多语言 UI（MVP 仅中文 UI）
