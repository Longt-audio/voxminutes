## 正文

大家好，分享一下我独立开发的一款桌面应用 **VoxMinutes**。

这是一个 100% 免费、完全本地运行的 Windows 会议助手，核心解决一个问题：**开线上会议时，对方的声音（系统播放）和我的声音（麦克风）能同时录下来、实时出文字，并且所有数据都不离开我的电脑。**

### 主要功能

- **双路同步录音**：系统音频 + 麦克风同时采集、自动混音，Zoom / 腾讯会议 / 飞书 / 网课都适用
- **实时流式转写**：X-ASR（中英低延迟） / SenseVoice（中/英/日/韩/粤语）双引擎
- **实时翻译**：Hy-MT2（腾讯混元）支持 13 种目标语言，另有轻量 OPUS-MT 中英互译
- **AI 会议纪要**：本地 GGUF 大模型（Qwen / Gemma）离线生成总结，也可接自己的 API
- **历史记录 & 导出**：SQLite 存储，支持搜索、编辑，导出 TXT / SRT / Markdown
- **模型管家**：应用内多源下载（GitHub / HuggingFace 镜像 / ModelScope）或本地导入，无需命令行
- **多语言界面**：中文 / English / 한국어 / 日本語

### 为什么做它

市面上会议转写工具要么按分钟收费，要么音频要上传云端，而且很多工具只能录麦克风或只能录系统声音。我想要一个**无账号、无订阅、无付费墙**的本地方案，于是自己写了一个。

### 隐私

音频、转写、翻译、总结全部在本地完成；除非主动配置远程总结 API，否则不与任何服务器交换内容。

### 技术栈

Tauri 2 + Next.js + Rust + sherpa-onnx + llama.cpp，AGPL-3.0 开源。

### 下载

- GitHub：https://github.com/Longt-audio/voxminutes
- 安装包：https://github.com/Longt-audio/voxminutes/releases

> 提示：安装包暂未做代码签名，Windows 可能出现 SmartScreen 蓝色提示，点「更多信息 → 仍要运行」即可。首次启动会引导下载 ASR 模型（国内直连镜像，无需代理）。

目前是 v0.1.x 早期版本，macOS / Linux 在计划中。欢迎大家试用，有任何问题（安装、模型下载、识别效果）都可以在 issue 里反馈，感谢！

## 高频回复模板

**Q: Mac 能用吗？**
> 暂时只有 Windows 版，macOS 在路线图中。可以先 star 一下，支持了第一时间更新。

**Q: 识别准确率怎么样？**
> 中文/英文用 X-ASR 或 SenseVoice，安静环境下准确率不错；嘈杂环境或口音重时会有误差。后续会加说话人分离和降噪。

**Q: 模型下载慢怎么办？**
> 应用内支持多源回退，也可以把链接复制到 IDM / aria2 / 迅雷下载后，在「设置 → 模型」里导入。
