# 知乎发布文案

## 文章标题

```
有哪些好用且免费的本地会议转写工具？——我开源了 VoxMinutes
```

## 文章正文

### 一、先回答这个问题

如果你希望：

- 线上会议的内容自动转成文字
- 对方的声音（系统播放）和自己的声音（麦克风）都能录到
- 实时翻译成中文或其他语言
- 所有数据留在本地，不上传云端
- 完全免费、无订阅

那我最近开源的 **VoxMinutes** 应该是一个值得尝试的方案。

### 二、VoxMinutes 是什么

VoxMinutes 是一款 Windows 桌面应用，基于 Tauri 2 + Rust 开发，AGPL-3.0 开源。

它最不一样的地方是：**同时录制系统音频和麦克风输入**，自动混音后做实时转写。这对 Zoom、腾讯会议、飞书、网课、播客访谈这类场景非常实用——很多工具只能录麦克风，无法录到对方声音。

### 三、主要功能

- **双路录音**：系统播放 + 麦克风同时采集
- **实时转写**：X-ASR（中英流式）/ SenseVoice（中/英/日/韩/粤语）
- **实时翻译**：Hy-MT2 支持 13 种目标语言，OPUS-MT 中英互译
- **AI 会议纪要**：本地 Qwen / Gemma GGUF 模型离线总结
- **历史与导出**：SQLite 存储，导出 TXT / SRT / Markdown
- **模型管家**：应用内下载或本地导入，无需命令行

### 四、隐私

音频、转写、翻译、总结全部在本地完成。除非主动配置远程 API，否则没有任何内容离开设备。

### 五、适合谁

- 远程办公、跨国会议频繁的职场人
- 需要整理英文网课/播客内容的学生/创作者
- 对云端 ASR 有隐私顾虑的用户
- 想找一个免费替代 Otter.ai / 讯飞听见的人

### 六、下载与安装

- GitHub：https://github.com/Longt-audio/voxminutes
- 安装包：https://github.com/Longt-audio/voxminutes/releases

> 安装包暂未代码签名，Windows 可能出现 SmartScreen 提示，点「更多信息 → 仍要运行」即可。首次启动会引导下载 ASR 模型，国内网络可直连镜像。

目前是 v0.1.x 早期版本，macOS / Linux 在计划中。欢迎在 issue 区反馈使用体验。
