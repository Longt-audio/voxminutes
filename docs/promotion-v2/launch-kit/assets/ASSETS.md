## 使用提示

- V2EX / 知乎：优先用 `chinese.gif`（体积小、加载快）
- Reddit / HN 相关讨论：`english.gif`
- 国内社交平台：短视频（竖屏）效果优于动图
- HN 不支持内嵌图片，只能用链接
