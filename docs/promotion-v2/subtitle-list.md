## 字幕样式建议

### 通用

- 字体：思源黑体 Bold / 阿里巴巴普惠体 Bold / Arial Black（英文）
- 字号：横版中文 42px / 英文 24px；竖版同比例放大 10–15%
- 颜色：白色填充 + 黑色描边 3–4px
- 位置：画面底部居中，距底边约 12–15%
- 动画：逐条淡入（可选）

### 关键词高亮

以下词建议用黄色/橙色高亮：
- 免费
- 本地
- 实时
- AI
- 13 种语言
- 系统 + 麦克风

### 竖屏安全区

- 上下各留 10% 给平台 UI（点赞、评论、分享按钮）
- 横版底部留 12% 给字幕，避免遮挡应用界面
