## 一、前言

VoxMinutes（以下简称「本软件」）是一款运行在你个人电脑上的会议记录工具，可以录制麦克风与
系统声音、实时转写、翻译并生成会议总结。

我们深知会议内容往往是敏感信息，因此本政策会**逐项说明**：哪些数据只留在你的电脑上、
哪些数据会在你使用特定功能时上传、上传给谁、保存多久。

**请特别注意：本软件不需要注册账号。** 我们不要求你提供姓名、手机号或邮箱。
当你首次使用远程服务时，我们仅使用你电脑的操作系统设备标识码为你建立一个匿名账号
（用于记录你的积分余额）。

我们建议你在开始使用前完整阅读本政策。你开始使用本软件，即表示你已理解并同意本政策。

## 二、我们收集哪些信息

### 2.1 只保存在你电脑上的信息（不上传）

以下数据**不会**上传到我们的服务器：

| 数据 | 保存位置 |
|---|---|
| 录音音频文件（`audio.mp4` 等） | 你在设置中选择的录音保存目录（默认是「用户主目录/recordings」） |
| 转写文本、译文、会议总结（`transcripts.json` / `metadata.json`） | 同上，会议文件夹内 |
| 本地数据库（会议记录、片段、设置） | 应用数据目录（macOS：`~/Library/Application Support/com.voxminutes.app`；Windows：`%LOCALAPPDATA%\com.voxminutes.app`） |
| 运行日志 | 程序安装目录下的 `logs/`；若该目录不可写（例如安装在 `C:\Program Files`），则回退到 `%LOCALAPPDATA%\VoxMinutes\logs` |
| 本地模型文件（语音识别 / 翻译 / 总结） | 模型目录（可在设置中自定义） |

> **卸载提示**：卸载本软件**不会**自动删除上述数据。如需彻底删除，请手动删除录音保存目录与
> 应用数据目录。

### 2.2 你主动提供给我们的信息

- **意见反馈**：反馈正文；可选上传的截图；可选填写的联系方式；可选附加的诊断日志。
- **授权码**：你从我们或我们的发卡平台获得的授权码（一串字符）。

> **诊断日志的脱敏**：当你在反馈中勾选「附加诊断日志」时，我们会在上传前自动抹除
> 授权码、API Key、Bearer Token 与操作系统用户名，并且只截取最近日志文件的尾部
> （每个文件最多 160KB，最多 2 个文件；选择「按时间窗」时每个文件最多 80KB）。
> **日志中不包含你的录音内容与转写文本。**

### 2.3 使用远程功能时产生的信息

只有当你**主动选择「远程」模型**或**使用需要联网的功能**时，才会产生以下数据：

| 数据 | 什么时候产生 | 说明 |
|---|---|---|
| 设备标识码 | 首次领取免费额度时 | 由操作系统提供（Windows 为 MachineGuid、macOS 为 IOPlatformUUID、Linux 为 machine-id），用于绑定你的匿名账号，防止同一台设备重复领取 |
| 授权码 | 每次调用远程服务时 | 作为身份凭证 |
| **音频数据** | 使用远程语音识别时 | 流式识别：按语音片段持续上传；离线（重新）识别：整段音频上传。详见 2.4 |
| **文本数据** | 使用远程翻译 / 会议总结时 | 待翻译的句子、待总结的转写文本会经我们的服务器转发给上游 AI 服务商 |
| 用量与计费记录 | 每次调用远程服务时 | 调用的模型、消耗的音频秒数或 token 数、时间、任务会话标识（用于把一次会议的多笔调用归为一组展示给你） |
| IP 地址 | 调用远程服务 / 领取额度时 | 用于防滥用与限流。记录在服务器访问日志中 |

### 2.4 关于音频数据的重要说明

- **本地模型**：使用本地语音识别模型时，音频**全程不离开你的电脑**。
- **远程流式识别**：音频被切分成很短的片段（通常几秒）持续发送到我们的服务器，
  由服务器转发给上游 AI 服务商，实时返回文字。
- **远程离线（重新）识别**：整段音频会上传到我们的服务器。若上游服务商要求「公网可下载的
  音频地址」，音频会由我们的服务器临时托管，且**最长 2 小时后自动删除**。
  为减少传输量，音频可能在上传前被转码为 16kHz 单声道 MP3（不影响识别结果）。
- 我们**不会**将你的音频用于训练模型，也**不会**将其用于本政策未说明的任何其他用途。

### 2.5 我们不收集的信息

以下信息我们**不收集、不读取、不上传**：

- 姓名、手机号、邮箱、身份证件信息（本软件不要求注册）
- 精确位置信息
- 通讯录、通话记录、短信
- 剪贴板内容
- 你电脑上的其他文件（本软件只访问你明确指定的录音目录、模型目录与导出目录）
- 你在软件内的操作行为埋点（本软件**未集成**任何第三方统计分析 SDK）

### 2.6 你不使用远程功能时

如果你只使用本地模型（本地语音识别、本地翻译、本地总结），并且不领取额度、不提交反馈，
那么除了本政策 2.3 中「IP 地址」在访问版本检查与公告接口时产生的服务器日志以外，
**我们不会收到你的任何数据**。

## 三、我们如何使用这些信息

1. 提供并维护远程语音识别、翻译、总结、语音合成服务；
2. 计算与展示你的积分余额和消费明细；
3. 防止滥用（重复领取免费额度、自动化刷量、盗用授权码）；
4. 排查故障与改进产品（仅基于你主动提交的反馈与脱敏日志）；
5. 履行法律法规要求的义务。

**我们不会**：出售你的个人信息；将你的音频或转写内容用于广告；在未经你同意的情况下
将你的内容用于模型训练。

## 四、信息的共享与第三方

### 4.1 上游 AI 服务商

使用远程功能时，音频或文本会经我们的服务器转发给以下服务商之一（取决于你选择的模型）。
我们会传输**完成该次请求所必需的最小内容**：

| 服务商 | 用途 | 所在地 |
|---|---|---|
| 阿里云百炼（DashScope） | 语音识别、翻译、总结、语音合成 | 中国大陆 |
| 火山引擎（豆包） | 语音识别 | 中国大陆 |
| 小米 MiMo | 语音识别、翻译、总结 | 中国大陆 |
| Deepgram | 语音识别 | 美国 |
| DeepSeek / Moonshot 等大模型服务 | 翻译、总结 | 中国大陆 |

各服务商对其收到的数据适用其自身的隐私政策，你可以在对应服务商官网查询。

### 4.2 你自己配置的「自定义 API」

本软件支持你填写自己的 OpenAI 兼容或 Anthropic 兼容接口地址。此时数据**直接由你的电脑
发送到你填写的地址**，不经过我们的服务器，我们无法访问这些数据，也不对其处理方式负责。

### 4.3 充值、支付与发卡

购买充值卡时，你是在我们的发卡平台上完成交易的。发卡平台与支付通道会收集
**完成交易与发货所必需的信息**（通常是邮箱与订单信息），这部分由其各自的隐私政策约束：

- 发卡平台：独角数卡
- 支付通道：虎皮椒（支付宝 / 微信支付）、PayPal

我们**不会**获取你的银行卡号、支付账号密码等支付凭证。

### 4.4 法律要求

在法律法规要求、司法机关或行政机关依法定程序要求时，我们可能依法提供相关信息。

## 五、信息的跨境传输

我们的服务器位于**中国香港**，上游 AI 服务商分别位于**中国大陆**与**美国**。

因此，当你使用远程功能时，你的音频片段或文本可能会被传输至你所在国家/地区以外的服务器。
我们会通过 HTTPS/TLS 加密传输，并要求服务商按约定用途处理数据。

如果你不同意此类跨境传输，请使用本地模型——本地功能完全离线，不涉及任何跨境传输。

## 七、你的权利

- **查询与导出**：你的录音、转写与总结都在你的电脑上，可随时查看、导出或删除。
  积分余额与消费明细可在「用户中心」查看。
- **删除**：删除本地会议文件夹即可删除对应录音与文本。如需删除服务器上的账号与记录，
  请通过 voxmin@qq.com 联系我们，我们会在核实后 15 个工作日内处理。
- **撤回同意**：你可以随时在设置中关闭「启用远程服务」。关闭后不再产生新的上传。
- **投诉**：如你认为我们处理你的个人信息侵害了你的合法权益，可向监管部门投诉。

本软件面向成年人设计。**不满十四周岁的未成年人**使用本软件，应取得其父母或其他监护人的同意。
监护人应指导未成年人使用，并注意会议内容中可能涉及他人个人信息的情形。

如果你发现我们在未取得监护人同意的情况下收集了不满十四周岁未成年人的个人信息，
请联系我们，我们会尽快删除。

## 九、我们如何保护你的信息

- 客户端与服务器之间、服务器与上游服务商之间全程使用 HTTPS/TLS 加密传输；
- 授权码保存在操作系统的凭据管理器中（macOS 钥匙串 / Windows 凭据管理器），不以明文写入配置文件；
- 诊断日志在上传前自动脱敏（授权码、API Key、用户名）；
- 服务器访问权限受限，仅运营者本人可访问生产数据库；
- 临时音频文件定时自动清理。

但请注意：**任何技术措施都无法保证百分之百安全**。请自行妥善保管你的授权码，
不要在不可信的设备上使用，并注意会议参与者的知情同意。
